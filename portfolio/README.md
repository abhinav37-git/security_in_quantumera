# Velith Systems Portfolio & Showcase

Interactive security software portfolio and live infrastructure visualizer.

🌐 **Live URL**: [https://velithsoftware.vercel.app](https://velithsoftware.vercel.app)

## Tech Stack
- HTML5, Modern Vanilla CSS, Vanilla JavaScript
- Three.js 3D dynamic scene rendering
- Vercel Serverless Functions (`/api`)

## Local Development
```bash
python3 -m http.server 3000
# or
npx serve .
```
Navigate to `http://localhost:3000`.
